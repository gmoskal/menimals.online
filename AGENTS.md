# Agent notes

## Git

Commituj i pushuj bezpośrednio na `main`. Nie twórz pull requestów ani gałęzi
roboczych, chyba że użytkownik wyraźnie o to poprosi.

## Polityka prywatności

Każda zmiana polityki prywatności musi zostać równolegle wprowadzona po polsku
i angielsku. Obie wersje mają być kompletne i równoważne znaczeniowo.

Przy każdej zmianie zaktualizuj widoczną datę i godzinę dokumentu, wraz ze
skrótem strefy, offsetem UTC i nazwą IANA `Europe/Warsaw`.
